# Pet-проект: Внутренние переводы между счетами (Финтех)

**Автор:** Студент 1 курса (Экономика) / Junior System Analyst
**Цель проекта:** Демонстрация навыков проектирования баз данных, описания API и моделирования бизнес-процессов для портфолио.

## 📌 Бизнес-цель (Vision)
Дать клиентам возможность мгновенно и безопасно переводить деньги между своими счетами внутри банка, без комиссии.

## 🛠 Стек и инструменты
*   **Базы данных:** SQL (PostgreSQL / SQLite)
*   **API:** REST, JSON
*   **Моделирование:** BPMN 2.0 (draw.io)
*   **Документация:** Markdown

## 📂 Структура репозитория
*   `01_Requirements/` — Бизнес-требования (FR/NFR) и User Stories.
*   `02_Design/` — Схема базы данных (ERD) и BPMN-схема процесса.
*   `03_Database/` — SQL-скрипт для создания таблиц и тестовых данных.
*   `04_API/` — Спецификация REST API (методы, JSON-запросы и ответы).

## 🚀 Ключевые особенности реализации
1.  **Идемпотентность:** Защита от двойного списания при сбоях сети (через уникальный `idempotency_key`).
2.  **Атомарность:** Списание и зачисление происходят в рамках одной SQL-транзакции (исключают потерю денег).
3.  **Безопасность:** Двухфакторная аутентификация (СМС) для переводов свыше 50 000 руб.
